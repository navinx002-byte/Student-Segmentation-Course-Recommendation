# 🤖 Saved Model Artifacts & Pipelines

This directory stores serialized model weights and preprocessing pipelines generated by the machine learning pipeline using `joblib`.

---

## 1. Serialized Pipeline Structure

When `StudentSegmenter.save(filepath)` is invoked, the exported `.joblib` dictionary encapsulates:
- `scaler`: Fitted `RobustScaler` with feature means and variance scales.
- `kmeans`: Fitted `RobustKMeans` with $K=4$ multidimensional centroids and minimum inertia.
- `pca`: Fitted `RobustPCA` with 2 principal components and variance ratios.
- `feature_names`: Explicit list of behavioral features used during training.
- `cluster_profiles`: Dictionary of mean feature vectors and generated persona labels.
- `metrics`: Silhouette Score, Davies-Bouldin Index, and Calinski-Harabasz validation scores.

---

## 2. Re-loading & Inference
To load a saved pipeline in Python:
```python
from src.segmentation import StudentSegmenter

# Load from disk
segmenter = StudentSegmenter.load("models/segmenter_k4.joblib")

# Predict cluster for new learner features
new_cluster_id = segmenter.kmeans.predict(new_scaled_features)
persona_name = segmenter.get_cluster_name(new_cluster_id)
```
